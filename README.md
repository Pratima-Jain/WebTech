# 🌐 WebTech

A collection of basic web development projects created while learning **HTML5** and **CSS3**. This repository contains beginner-friendly examples and practice projects to understand the fundamentals of frontend web development.

---

## 📌 About

This repository is built for learning and practicing the core concepts of web development. It includes simple web pages and UI designs created using only HTML and CSS.

The goal is to strengthen the basics before moving on to JavaScript and modern frontend frameworks.

---

## 🛠️ Technologies Used

- HTML5
- CSS3

---

## 📚 Topics Covered

### HTML
- HTML document structure
- Headings, paragraphs, and text formatting
- Images and hyperlinks
- Lists (Ordered & Unordered)
- Tables
- Forms and input elements
- Semantic HTML (`header`, `section`, `article`, `footer`, etc.)
- Div and Span
- Audio and Video elements

### CSS
- Selectors
- Colors and Backgrounds
- Fonts and Typography
- Margin and Padding
- Borders and Border Radius
- Box Model
- Display properties
- Flexbox
- Positioning
- Width and Height
- Hover Effects
- Basic Responsive Design
